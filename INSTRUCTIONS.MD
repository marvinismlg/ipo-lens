IPO-LENS - Quick Start Instructions

1. Clone or download the project repository.

2. Open a terminal in the IPO-LENS project folder.

3. Install the required Python packages:
   pip install -r requirements.txt

4. Make sure the project structure remains unchanged:
   - Financial Data/
   - Prediction Engine/
   - User Interface/

5. Run the application:
   python "User Interface/ui.py"

6. The UI will open locally.

7. Use Score & Predict to:
   - Run the SpaceX lockup prediction
   - Compare SpaceX with META, BABA, RKLB, or ASTS

8. The application will automatically build and validate the financial dataset before running the prediction engine.

Note:
IPO-LENS requires an internet connection when refreshing Yahoo Finance and SEC data.
